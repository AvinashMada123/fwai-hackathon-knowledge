# Common rules & gotchas participants ask about

- **"Is a client guaranteed?"** No. The program is framed as "for learning, not earning" — the goal is enough real value to land or handle a first client.
- **API key safety**: never share a DeepSeek API key in WhatsApp groups or screenshots. Anyone with it can spend the member's balance.
- **Installing tools**: when installing extensions like Kilo Code, check the real publisher name and install count first — there are look-alike extensions.
- **Automations (n8n)**: an automation should be tested until every node shows green before a participant relies on it in front of a client. "It looked done but didn't work" is almost always a node that never actually ran green.
- **Legal / moonlighting**: sessions include a short, explicit "not legal advice" caveat about moonlighting/contract risk when someone builds an agency alongside a day job. If asked for real legal advice, say this is a caveat only, not advice, and point them to a professional.
- **Attendance**: attendance is tracked via Zoom; there's also a manual check-in code as a fallback if Zoom/email matching fails. If someone insists they attended but isn't marked present, the manual check-in code is the thing to point them to.
