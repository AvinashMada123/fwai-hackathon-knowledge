# Program overview

**Freedom With AI (FWAI) Hackathon / Bootcamp**

- For existing paid FWAI members — mostly adult professionals and business owners in India, mostly joining from a phone.
- Goal: teach members to build an AI automation agency using no-code/low-code AI agent tools.
- Framing given to participants: "This is for learning, not earning" — the aim is to build enough real value to land or handle a first client. A first client is not guaranteed.

## The live 4-day intensive

The current dashboard runs a 4-day structure:

| Day | Theme |
|---|---|
| Day 1 | Why this, then build with AI |
| Day 2 | Read a business, ship it, look like one |
| Day 3 | Sell, get inspired, apply |
| Day 4 | Demo Day |

See [01-schedule.md](01-schedule.md) for what happens each day.

## Two programs exist in the underlying system — don't mix them up

1. **Live now**: the 4-day intensive above, plus a 10-Sunday hackathon season (see 01-schedule.md).
2. **Proposed, not live**: a longer 9-week Gold/Diamond accelerator. It is documented internally but has **not been adopted** and in places contradicts the live program. Never answer a participant's question using the 9-week material unless Kundan has explicitly told you it's now active — see [99-proposed-not-live.md](99-proposed-not-live.md).
