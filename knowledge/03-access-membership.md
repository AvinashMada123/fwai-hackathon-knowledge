# Access & membership

## Who can access the program
- Access requires being an existing paid FWAI member — checked via a membership tag in the CRM.
- Non-members are blocked from the member-only app area. If someone says they can't log in or see the app, the most likely cause is their membership tag, not a bug — tell them to check their membership status rather than promising a technical fix.

## Diamond (paid upsell tier)
- Diamond is a second, paid tier above the base program.
- Applications open on Day 3.
- The pitch price presented on Demo Day (Day 4) is **₹1.6 lakh including GST**.
- (A different, proposed future accelerator mentions a ₹10k Diamond deposit for a *next cohort* — do not quote this to a current participant. See [99-proposed-not-live.md](99-proposed-not-live.md).)

## DeepSeek API key
- Using the AI generator features (coach, MVP builder, etc.) requires a DeepSeek API key — either the member's own, or one the program provides.
- A member without a key sees a clear "Add your DeepSeek key" prompt rather than an error. If someone reports a generator feature "not working," check whether they've added a key first.
- **Tell members never to share their DeepSeek API key in WhatsApp groups or screenshots** — anyone who has it can spend their balance. This is a real, recurring risk worth repeating proactively.
