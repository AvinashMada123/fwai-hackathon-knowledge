# Communication channels

- **Zoom**: live sessions are hosted here. Attendance syncs from the Zoom participants report.
- **WhatsApp**: used for reminders and outreach follow-ups.
- **In-app "Ask the coach" bot**: answers beginner questions with plain, clickable-style instructions inside the dashboard itself — some participants may already be getting answers there before they reach Kundan.
- **Fallback attendance**: a manual check-in code is used when Zoom/email attendance matching fails for someone.
