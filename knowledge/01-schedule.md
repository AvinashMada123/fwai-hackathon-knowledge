# Structure & schedule (live program)

- Live sessions run on **Sundays at 19:30 IST**. The hackathon season is 10 sessions total.
- The 4-day intensive curriculum breaks down like this:

## Day 1 — Why this, then build with AI
- "20-minute win": define your niche
- Skills, tools, and mindset for the program
- Agent setup: VS Code + Kilo Code + DeepSeek
- Productivity use cases
- Automations (n8n)
- Chatbot build
- MVP build

## Day 2 — Read a business, ship it, look like one
- Deploy your MVP to Vercel
- Build a scheduled AI agent
- Business branding and marketing assets
- Outreach plan and sales script

## Day 3 — Sell, get inspired, apply
- Sales system
- Diamond program application (see 03-access-membership.md)
- Outreach follow-up
- "Three business owners" build — this is an overnight build; submissions close when Day 4 starts

## Day 4 — Demo Day
- Business owners review the top graded builds live and can buy them
- Diamond pitch is presented (₹1.6 lakh including GST)

## Cadence expected from participants
- One outreach/follow-up message per day
- One ad per day for seven days
- Consistency is emphasized over talent — this is the answer to "am I behind" type questions.
